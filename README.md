# CerdasIn

Struktur deployment sudah diperbaiki agar `package.json` berada di root repository.

## Abasthan
Build Command: `npm install`
Start Command: `npm start`

Port: gunakan `process.env.PORT` (sudah ditangani server.js).

Catatan: ranking dan room pada paket ini tersimpan di memori server. Nexa AI belum terhubung ke penyedia AI karena membutuhkan API key/server secret.
